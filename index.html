Stock Manager

An inventory control app written from scratch: products, stock in and out, low-stock alerts, roles (admin and operator), an audit trail of who changed what and when, a dashboard, and an inventory report with restock suggestions and AI analysis.

The backend is three NestJS services behind an nginx gateway. Each service owns its data: auth and stock have separate databases, and reports reads stock over HTTP. The business rules live in tested domain classes, and every error has a stable code that the frontend translates.

What is in the repository

  • Business rules in tested domain classes, with unit tests for each rule and integration tests against a real PostgreSQL database.
  • A race guard for stock withdrawals, enforced in the database, with an integration test that fails if the guard is removed.
  • Passwords hashed with scrypt, JWTs signed with RS256, a lockout after repeated failed sign-ins.
  • API documentation in Swagger for every route, with the error responses each route can return.
  • Browser end-to-end tests run in CI against the full Docker stack.

Next improvements
